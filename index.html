01 / FEATURES

The browser, stripped back.

ARX focuses on the parts of a desktop browser you actually interact with, without building a second operating system around them.

01

Web browsing

Modern pages rendered through WebKitGTK 4.1 with a native Linux application shell.

02

Tabs

Multiple tabs, switching, closing, reopening recently closed pages, and private tabs.

03

Navigation

Address-bar navigation with URL parsing, back, forward, reload, keyboard shortcuts, and search handling.

04

Privacy controls

Integrated privacy settings, private browsing contexts, website-data controls, and configurable browser behaviour.

05

Downloads

Download handling with destination selection, progress tracking, filesystem storage, and desktop notifications.

06

Browser data

History and bookmarks are handled locally rather than relying on an online account or browser sync service.

03 / INSTALL

Download. Extract. Run.

The release archive contains the packaged ARX Browser binary for compatible Linux x86_64 systems.

Linux x86_64

Download the latest archive, extract it, and launch arx-browser.

terminal 
$ tar -xzf ARX-Browser-v0.4.0-Linux-x86_64.tar.gz

$ cd ARX-Browser-v0.4.0-Linux-x86_64

$ ./arx-browser
